# Terminal-Icons-for-Linux
Terminal-Icons for Linux is a Bash script displaying Nerd Fonts icons for files and folders. It installs scripts and theme data to ~/terminal-icons/, adds sourcing to ~/.bashrc, and provides ti command for long listing (-l), or tree view (--tree) modes with color controls. Requires Bash 4.3+, GNU coreutils, and a Nerd Fonts-enabled terminals.
